# MA5/MA10 均线交叉策略

按 `tradingday` 聚合分钟数据，取每个交易日最后一根有效分钟 K 线的收盘价计算**日线**简单移动平均线。MA5 从下向上穿过 MA10 时转多，从上向下穿过时转空。交叉在当日收盘后确认，开仓与平仓订单均在**下一交易日 09:05 分钟 K 线的开盘价**成交，并按框架配置加入滑点及手续费。反向时平仓和反向开仓在同一个 09:05 事件依次成交。

从空仓启动时先累积至少 10 个**完整交易日**的收盘价；没有观察到交叉之前不建立仓位。专用 HDF5 数据源仅把每日的 09:05 行情和日终收盘行情送入回测引擎，避免逐根遍历所有分钟 K 线。若下一交易日缺少 09:05 行情，订单作废，不会在日终误成交。使用框架的 `NotionalSizer` 决定开仓手数，平仓使用已成交持仓手数。

可在 `strategy/config/strategies.yaml` 的 `params` 中用 `fast_period`、`slow_period` 覆盖默认的 5 和 10，单位均为交易日。`session` 统一记为“全天”。目前这条快速路径支持单策略、`hdf5_index` 数据源。
